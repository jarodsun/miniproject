# 模板需求说明

## Body 模板需求

### 直辖市级别 Body 模板 (body_municipality_template.html)

参考网站：https://www.yisu.com/city/

#### 页面布局结构

**整体布局**：两栏模式（左右分栏）

**页面结构从上到下**：

1. **面包屑导航**
   - 位置：页面最顶部
   - 格式：`首页 > 地区导航` 或 `首页 > {直辖市名称}`
   - 作用：显示当前页面在网站中的位置层级

2. **两栏布局容器**
   - 左侧栏：内容区域
   - 右侧栏：城市导航列表

#### 左侧栏内容

**左侧栏从上到下包含**：

1. **Banner 轮播区域**
   - 位置：左侧栏最上部
   - 内容：轮播图片/广告横幅
   - 参考：https://www.yisu.com/city/ 中的 banner 区域
   - 可以包含多个轮播项，支持自动轮播

2. **云服务器产品购买区块（3个）**
   - 位置：Banner 下方
   - 数量：固定 3 个产品区块
   - 每个产品区块包含：
     - 产品名称（如：入门型优惠套餐、独立体验套餐、畅销独立套餐）
     - 地区信息（如：香港二区、华中一区）
     - 产品规格信息：
       - 规格（如：1核 4G、4核 12G）
       - 带宽（如：2M、5M、10M）
       - 独享IP（如：1个）
     - 价格信息：
       - 优惠价（如：145 元/首月）
       - 原价（如：145元/月）
     - 购买按钮（"立即购买"链接）
   - 样式：参考 https://www.yisu.com/city/ 中的云服务器产品区块样式

#### 右侧栏内容

**右侧栏内容**：

1. **城市导航列表**
   - 位置：右侧栏全部区域
   - **注意**：不要显示"云服务器"、"高防服务器"等 tab 切换标签
   - 直接显示城市导航列表
   - 列表结构：
     - 按地区分组（如：直辖市、华北地区、东北地区等）
     - 每个地区下显示该地区下的所有区县
     - 区县以链接形式展示，点击跳转到对应的区县页面
   - 格式示例：
     ```
     直辖市：
     东城区 | 西城区 | 朝阳区 | 丰台区 | ...
     ```
   - 链接格式：`{区拼音}/index.html`

#### 变量说明

模板中需要替换的变量：

- `{直辖市名称}` - 直辖市名称（如：北京市、天津市、上海市、重庆市）
- `{面包屑}` - 面包屑导航 HTML（如：`<a href="../index.html">首页</a> > 地区导航`）
- `{banner}` - Banner 轮播区域 HTML（可以是从主站获取或静态内容）
- `{产品区块1}` - 第一个云服务器产品区块 HTML
- `{产品区块2}` - 第二个云服务器产品区块 HTML
- `{产品区块3}` - 第三个云服务器产品区块 HTML
- `{城市导航列表}` - 右侧栏的城市导航列表 HTML（包含所有区县的链接）

#### 实现说明

1. **面包屑**：根据当前页面层级动态生成
2. **Banner**：可以从主站获取或使用静态内容
3. **产品区块**：3 个云服务器产品信息，可以是固定内容或从配置/API 获取
4. **城市导航列表**：根据 `pcas.json` 数据动态生成，列出该直辖市下的所有区县

#### 样式参考

整体样式参考 https://www.yisu.com/city/ 的布局和设计风格，但右侧栏不包含 tab 切换功能，直接显示城市导航列表。
